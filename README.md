# Eco Friendly Store 🌱

متجر إلكتروني صديق للبيئة - تسوق بمسؤولية، احمِ كوكبنا

## 🌟 المميزات الحالية

✅ صفحة رئيسية ترحيبية
✅ صفحة تسجيل احترافية بتصميم بيئي
✅ نماذج تفاعلية مع التحقق من البيانات
✅ دعم كامل للغة العربية (RTL)
✅ تصميم متجاوب مع جميع الأجهزة
✅ API لاستقبال بيانات التسجيل

## 🚀 قريباً

- 💾 ربط قاعدة بيانات MongoDB
- 🔐 نظام تسجيل دخول آمن
- 🛍️ عرض المنتجات البيئية
- 🛒 سلة المشتريات
- 💳 بوابة الدفع الإلكتروني

## 📁 هيكل المشروع

```
eco-friendy.com/
├── server.js              # السيرفر الرئيسي (Express)
├── package.json           # التبعيات والإعدادات
├── .gitignore            # الملفات المستثناة
├── README.md             # هذا الملف
└── public/               # الملفات العامة
    └── register.html     # صفحة التسجيل
```

## 💻 التثبيت المحلي

```bash
# 1. استنسخ المستودع
git clone https://github.com/platformathar-dev/eco-friendy.com.git

# 2. ادخل إلى المجلد
cd eco-friendy.com

# 3. ثبت التبعيات
npm install

# 4. شغل السيرفر
npm start
```

الموقع سيعمل على: http://localhost:3000

## 🌐 الروابط (Routes)

- `/` - الصفحة الرئيسية
- `/register` - صفحة التسجيل
- `/login` - صفحة تسجيل الدخول (قريباً)
- `/api/register` - API لإنشاء حساب جديد

## 🛠️ التقنيات المستخدمة

- **Backend:** Node.js + Express.js
- **Frontend:** HTML5 + CSS3 + JavaScript
- **Hosting:** Hostinger
- **Version Control:** Git + GitHub
